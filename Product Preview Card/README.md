# Product Preview Card

<img src="../Product Preview Card/ProductCard.png" alt="Product Preview Card" width="700">

A responsive product preview card built with **HTML and CSS**.

The project focuses on creating a clean product card layout with responsive behavior for different screen sizes.

## Built With

* HTML5
* CSS3
* Flexbox
* Responsive Design

## What I Practiced

* Creating responsive card layouts
* Using Flexbox for page structure
* Responsive images
* Typography and spacing
* CSS media queries
